QUICK START COMMANDS
==============================================================================

USING DOCKER COMPOSE:
  docker-compose up -d          # Start all services
  docker-compose logs -f        # View logs
  docker-compose down           # Stop services

USING ASPIRE (Development):
  cd AppHost
  dotnet run                    # Start Aspire Dashboard

ACCESS SERVICES:
  Web App:              http://localhost:5173
  Course API:           http://localhost:8080/swagger
  User API:             http://localhost:8081/swagger
  Instructor API:       http://localhost:8082/swagger
  PgAdmin:              http://localhost:5050
  Aspire Dashboard:     http://localhost:4317

KUBERNETES:
